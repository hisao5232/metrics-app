# Pro-Mechanic Suite (Android)
### 建設機械エンジニアのための現場支援ツール

建設機械の修理現場で培った知見を形にした、実用的なAndroidアプリです。
第一弾として「油圧シリンダー推力計算」機能を搭載しています。



## 🛠 主な機能

### 1. 油圧シリンダー推力計算
シリンダーの内径、ロッド径、リリーフ圧力を入力するだけで、瞬時に「押し」「引き」それぞれの推力を算出します。
- **計算式の表示**: 現場での根拠説明に役立つよう、面積計算から換算係数（10.197）を含めた全工程を表示。
- **ダークモード対応**: 屋外や薄暗い整備工場内でも見やすいUI。

## 🚀 開発環境
- **OS**: Ubuntu 24.04 (VPS: Xserver)
- **Language**: Python 3.11
- **Framework**: Kivy, KivyMD
- **Build Tool**: Buildozer
- **Fonts**: Noto Sans JP (日本語文字化け対策済み)

## 📦 インストール方法
現在、開発中のためAPK形式での配布を行っています。

1. 本リポジトリから `bin/*.apk` をダウンロード。
2. Android端末で「不明なアプリのインストール」を許可してインストール。
